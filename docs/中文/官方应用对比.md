# 官方 MasterHUB 应用与 HubDeck 对比

原文：[docs/OFFICIAL-APP.md](../OFFICIAL-APP.md)，写于 2026-10-11。译文基线 `0cbdde3`，2026-10-22。此为历史调查，表格中的状态没有按后来的代码更新；“已有”也包含实现但待实机验证的项目。

记录官方 Cooler Master 软件功能、承诺未交付内容，以及 HubDeck 对应能力。

来源：官方 1.0.0.113（2026-05-27 安装包），为互操作而使用并作为数据阅读，了解动作和 profile，没有复制代码，描述采用作者自己的话；Kickstarter、厂商网页与评测；HubDeck 的 `README.md`、`docs/PRESETS.md`、`engine/actions.rs`。HubDeck 状态分已有、部分、缺失并说明原因；built 且待硬件测试仍算已有。

## 官方应用功能

Electron + Vue，加独立 CPU/GPU sensor daemon。11 个动作组、约 170 动作，多为 Adobe 固定 hotkey；每动作声明适用 keys、dial、knobs、rollers、faders。

### `.mhz` 文件

以下来自官方代码阅读；没有真实官方文件，importer 只用测试构造文件验证：

- zip：每 profile 一 JSON，名字是 profile number 与 base serial，无后缀；`uploadImages/` 放原 JPG/PNG/GIF；`gifPools/` 放按 hash 命名预切帧，HubDeck 忽略；多 profile 导出为多个 `.mhz` 的 zip。
- 文件名 `masterHubConfig_profile_<name>.mhz` 含 profile 名。
- 各模块类型一入口，再按 serial 为 key：`keypad` 页列表，每页 15 键；`knobsList` 三旋钮 rotateR/rotateG/rotateB；`dialEncoder`；`rollerBlock` left/right；`sliders5List` 0–4；另有 deviceLightingEffect、收藏颜色、未发布 touch46s/touch50s。
- 按键有 `btnFunc`（hot-key/web-url/scenes 等）、title/显隐、`{r,g,b}` 背景/文本、图片路径、键名列表如 `["Control","Z"]`，以及 url/appFilePath/content/dropdownOption/selectSceneId 等；multi-task 保存类似按键的动作列表，folder 保存 15 键。
- knobs/dial 存多功能列表，按下切下项；每项有 action id 与 left/right，rollers 为 up/down，各有 choice/hotkey。
- OBS source/filter/media input 存 internal id，应用音量存 PID，重启失效；HubDeck 导入时留空 name，待用户填写。

HubDeck 导入各类型第一个模块，pages、folder 转带 Back 的 page；转换 key names 的 hotkey、URL/app/file、text、media、volume、scroll、间隔 280 ms 的 multi-task（沿用官方时序）、brightness、profile、timer、clock、12 Twitch 动作；OBS record/pause/stream/replay/virtual camera/studio/transition/scene/collection/profile/screenshot；Streamlabs record/stream/studio/transition；空名的 Streamlabs scene、两者 source visibility/mute/mixer、OBS filter；knob/dial 功能列表转 Modes；title、非默认色与图片。

其余 Discord、MasterCTRL、无存储 hotkey 的 Adobe 动作、录制 macro、灯效转成标签 Not supported: <action> 的空控件。按官方 App.vue 事件：rotateB、rotateR、rotateG 对应 HubDeck knobs 1–3；right roller 为 1，left 为 2，2026-10-12 修正，此前靠猜。

### 官方代码中的未发布硬件

M3704 按键有单键图片/颜色；Touch46（M4600）、Touch50（M5000）带标题/颜色选择；另有 M3700/M4300 SDK。store 残留温湿度、光、CO2 的 Hub2 / case sensor 字段。现售硬件不可用，HubDeck 不支持，等实际模块出现再考虑。

## 差距：从官方切换最先感到缺少的项目

1. OBS media source 的 play/pause/restart 和按键计时；其他 OBS 动作 2026-10-11 加入。
2. `.mhz` 导入，2026-10-11 `engine/mhz.rs` 已做，待真实用户文件。
3. Twitch 动作同日已做，需自己的 app 注册登录。
4. Streamlabs 同日已做，待真实服务。
5. key/dial timer 与 clock 同日已做，无 analog clock。
6. `leds.rs` hardware effects 同日已做，同模块不同 knob 效果待实机。
7. 麦克风和 OBS PTT/PTM 同日已做。
8. 控件调亮度与上/下 profile 同日已做。
9. key 字体大小、对齐、独立图标色，计划给 Look 三字段并用于 render.rs。
10. 声音文件同日已做，sound.rs 的 rodio 独立线程、首次播放启动。
11. macro recorder 同日 engine 已做，待 multi-action editor 的 Record 按钮。
12. 每播放器快进退同日已做 Seek in a player。
13. Illustrator preset 同日已做。
14. 多底座计划中。
15. 更多语言，官方 17；计划公开发布后开放 i18n.ts 社区翻译。
16. 软件更新，phase 8 Tauri updater 计划。
17. CPU 温度和 AMD/Intel GPU 同日由 lhm.rs 读取 LHM WMI，仅显示时读。
18. Discord voice 原文称开源 app 暂无法实现，保留 hotkey。
19. 小项：双击 .mhz/HubDeck 文件、收藏颜色、底座/模块命名。

不复制的功能：固件升级、CM 账号和云上传（本地备份/共享目录替代）、仅 CM 硬件的 MasterCTRL。
