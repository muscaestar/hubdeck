# 从终端使用 HubDeck

原文：[docs/CLI.md](../CLI.md)。基线 `0cbdde3`，2026-10-22。

HubDeck 程序也接受供脚本、快捷方式和其他工具使用的命令。它们通过本地 API 与运行中的 HubDeck 通信，见[插件与本地接口](插件与本地接口.md)，因此先启动 HubDeck。

```text
hubdeck cli status                     活动与 home profile，以及已连接模块
hubdeck cli profiles                   列出所有 profile 及 id（* 活动，^ home）
hubdeck cli profile <name or id>       立即显示指定 profile，并设为 home
hubdeck cli key <1-15> --label TEXT    修改活动 profile 的按键标签
hubdeck cli key <1-15> --icon NAME     修改图标，名称见 Settings 的图标选择器
hubdeck cli key 3 --label Mute --page tools   修改另一页的按键
hubdeck cli lights <rainbow|color|profile|off> [#rrggbb]   整台设备的灯光风格
```

按键从左到右、从上到下编号 1–15。成功退出码 0，失败为 1 并打印原因。Windows 程序为 `C:\Program Files\HubDeck\hubdeck.exe`（或实际安装位置）；macOS 为 `/Applications/HubDeck.app/Contents/MacOS/hubdeck`。

示例：

```sh
# 计划任务：早上切换到专注 profile
hubdeck cli profile "Night focus"

# 在按键 15 显示构建结果
hubdeck cli key 15 --label "Build OK" --icon check
```
