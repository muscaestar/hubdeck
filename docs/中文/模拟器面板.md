# Sim panel：把控制台作为 joystick

原文：[docs/SIM-PANEL.md](../SIM-PANEL.md)。基线 `0cbdde3`，2026-10-22。以下为原作者操作说明，本轮未安装驱动或操作硬件。

HubDeck 可让飞行、赛车、太空模拟器把设备识别为 game controller：按键为 joystick button，推杆/旋钮为轴（油门、混合比、配平），滚轮点按按钮。模拟器无需了解 HubDeck，在游戏自身设置里像普通 joystick 一样绑定。

依赖免费虚拟 joystick driver **vJoy**，HubDeck 不捆绑，用户需另装一次。仅 Windows；vJoy 无 macOS 版，Mac 的 joystick 动作会说明。

## 1. 安装 vJoy

1. 下载支持 Windows 10 / 11 的签名 fork 安装包：[BrunnerInnovation/vJoy Releases](https://github.com/BrunnerInnovation/vJoy/releases)，原文写作时为 2.2.2.0。
2. 运行并接受 driver，按要求重启 Windows。
3. Windows 11 安装失败见 fork issue；常见原因是残留旧 vJoy（先卸载）或 Windows Memory integrity。

HubDeck 通过安装器记录的目录自动寻找 vJoy，否则找 `C:\Program Files\vJoy\x64`，无需在 HubDeck 配置。

## 2. 配置虚拟 joystick

开始菜单打开 **Configure vJoy**：

1. 顶部选 device **1**，底部勾 **Enable vJoy**。
2. **Axes** 全选八个：X、Y、Z、Rx、Ry、Rz、Slider、Dial/Slider2。
3. **Number of buttons** 为 **32**，Sim panel 用 19 个，多设无额外成本。
4. **POV hat switch** 为 1；需要 Joystick hat 斜向则选 **Continuous**。
5. **Apply**。

开始菜单 **Monitor vJoy** 显示实时轴与按钮；Sim panel 按键按下，对应按钮点亮。Windows `joy.cpl` > vJoy Device > Properties 也能查看。

Joystick Gremlin、FreePIE 等已占用 device 1 时，给 HubDeck device 2：在 Configure vJoy 启用，并在动作的“vJoy device”设 2。

## 3. 在 HubDeck 添加 Sim panel

`+` > **Sim panel**。Microsoft Flight Simulator 2020/2024、DCS World、X-Plane、iRacing、Star Citizen 在前台时自动切入，可在 profile 修改列表。

| 控件 | 功能 | vJoy |
|---|---|---|
| Keys 1–15 | B1–B15，按多久保持多久，无长按/双击判断延迟 | buttons 1–15 |
| Fader 1 | Throttle 油门 | Z axis |
| Fader 2 | Mixture 混合比 | Rx axis |
| Fader 3 | Propeller 螺旋桨 | Ry axis |
| Fader 4 | Flaps 襟翼 | Slider |
| Fader 5 | Trim 配平 | Dial (Slider2) |
| Dial | 与推杆 5 同轴精调，每步 0.5%；按下回中 | Dial (Slider2) |
| Knobs 1–3 | X、Y、Rz，每步 2%；按下回中 | X、Y、Rz |
| Roller 1 | 向上 B16、向下 B17 | buttons 16、17 |
| Roller 2 | 向上 B18、向下 B19 | buttons 18、19 |

右侧设置可改变：

- **Joystick button**：按键持续按住的按钮；旋钮、滚轮、dial 则为各方向每格点按的按钮，每次保持 40 ms，让每帧读取一次的模拟器捕获。
- **Joystick axis**：轴、每格变化量、按下行为（center、minimum、maximum、nothing）。旋钮接着 HubDeck 最后设置值变化，也包括同轴推杆设定值。
- **Joystick hat**：按住按键时保持方向，可作 D-pad / 环视。

托盘暂停、电脑休眠、HubDeck 退出时释放所有按钮并归还 joystick。

## 4. 在模拟器绑定

通用方法：控制设置选 **vJoy Device**，选功能，点 assign / scan input，再移推杆或按键。很多模拟器给新 joystick 默认 X/Y 副翼/升降舵；先清除 vJoy 默认绑定，避免旋钮意外控制飞机。

- **Microsoft Flight Simulator 2020 / 2024**：Options (Settings) > Controls > 顶部选 vJoy Device > 创建空 profile > 搜 Throttle axis、Mixture axis、Propeller axis、Flaps axis、Elevator trim axis > Search by input / Scan input > 移推杆 > Validate。按钮同理，例如 Landing gear (toggle)。
- **DCS World**：Options > Controls > 选飞机 > vJoy Device 列；先用 Clear category 清默认轴。轴：Axis Assign > 功能（如 Thrust）> 双击 vJoy 单元格 > 移推杆；Axis Tune 可反向或加曲线。按钮双击功能行的 vJoy 单元格后按键。
- **iRacing**：Options > Controls；按钮点击功能如 Pit limiter、Brake bias + 后按键；handbrake、clutch 等轴使用 Calibrate，把推杆移遍全程。
- **Star Citizen**：Options > Keybindings > Advanced Controls Customization。vJoy 显示为 js1/js2，顺序见 Options > Devices；绑定按钮、轴，如 Z 油门、旋钮 strafe。
- **X-Plane 12**：Settings > Joystick > vJoy Device > 移推杆并选轴功能，按钮在下方。

## 排障

| HubDeck 提示 | 操作 |
|---|---|
| Install vJoy to use the deck as a joystick | 按第 1 节安装，10 s 后自动重查，无需重启 |
| vJoy is installed but switched off | Configure vJoy > Enable vJoy |
| vJoy device 1 is not set up | 按第 2 节启用该设备 |
| ... is used by another program | 关闭其他 feeder 或换 device number |
| ... has 8 buttons, button 16 needs more | 提高按钮数量 |
| ... has no RZ axis | 勾选对应轴 |
| ... has four directions only | POV hat switch 选 Continuous，支持斜向 |

游戏看不到变化时，可能只在启动枚举 joystick；先配好 vJoy，再启动模拟器。
