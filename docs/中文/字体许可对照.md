## 定义

- **Font Software**：版权人依本许可发布且明确标识的一组文件，可含源文件、build script、文档。
- **Reserved Font Name**：版权声明后指定的保留名。
- **Original Version**：版权人分发的原始字体组件集合。
- **Modified Version**：增加、删除、替代部分或全部组件，改格式或移植环境所成的派生版本。
- **Author**：对 Font Software 有贡献的设计师、工程师、程序员、技术作者或其他人。
