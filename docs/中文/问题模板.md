# GitHub 问题模板中文对照

最后更新：2026-10-22。原文：[bug.yml](../../.github/ISSUE_TEMPLATE/bug.yml)、[feature.yml](../../.github/ISSUE_TEMPLATE/feature.yml)、[slots.yml](../../.github/ISSUE_TEMPLATE/slots.yml)、[config.yml](../../.github/ISSUE_TEMPLATE/config.yml)。保留原模板字段和行为，以下供中文阅读与填写参考。

## Something does not work — 某些功能不工作

描述：bug、崩溃、找不到模块或行为异常。标签 `bug`。

感谢你花时间反馈。最快的定位方式：HubDeck 顶部 **Feedback > Report a problem** 会填入下方诊断；也可在 **Settings > Help and feedback > Save diagnostics**（托盘菜单也有）保存并附加文件。文件包含版本、模块与日志，去掉 web 地址、keys 和路径。

- **发生了什么，原本期待什么？**（必填）示例：“我转动 knob 2（Volume，Spotify），没有变化；我期待 Spotify 音量减小。”
- **影响程度？** 选项：无法使用 HubDeck / 需要的功能不工作 / 麻烦，但可以绕过 / 小问题。
- **复现步骤：** 1. …；2. …。
- **HubDeck 版本和系统**（必填）：例如 `HubDeck 0.1.0, Windows 11 23H2 / macOS 15.5`。
- **Diagnostics：** 用 Feedback > Report a problem 时自动填写版本、系统、模块、最近 warning/error，移除地址、keys、路径。也可把保存的诊断文件拖到这里。

## Something is missing — 缺少某项功能

描述：希望增加 action、应用集成、preset 或其他改善配置的功能。标签 `idea`。

- **希望 HubDeck 做什么？**（必填）示例：“用 knob 在 DaVinci Resolve 时间轴中定位。”
- **会怎样使用？** 说明自己的配置、应用、模块，有助于做出合适的功能。
- **目前用什么替代办法？**

## Where my modules sit — 我的模块位置

描述：分享底座上的模块布局，帮助 HubDeck 正确放置每个人的模块；**Arrange modules > Share this arrangement** 自动填写。标签 `slots`。

HubDeck 根据模块使用的 USB port 推算位置。有些 port 还没实物验证。如果模块画错，而你在 Arrange modules 中修正过，分享可帮助下一位用户。仅发送下面的 slot、位置与旋转，提交前可以看见全部内容。

- **Modules（kind、slot、column、row、turn）**（必填）：每模块一行，由 HubDeck 填写，保持原始 text。
- **底座朝向**（必填）：默认平放 / 向右转 90° / 向左转 90° / 倒置。
- **Checked**（必须勾选）：安排后 HubDeck 的图示与桌面实物一致。
- **HubDeck 版本和系统：** 例如 `HubDeck 0.1.0, Windows`。
