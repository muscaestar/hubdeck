## 报告漏洞

安全问题请勿公开提交 issue。请发邮件至 przemotar+hubdeck@gmail.com，说明发现、复现方法和影响范围。原作者承诺数日内答复；修复准备好后尽快发布，除非你要求匿名，否则会注明贡献者。

## HubDeck 中与安全有关的行为

- 只通过 USB HID 与 MasterHUB 模块通信。不会发送固件升级、序列号、工厂数据、恢复出厂或保存 flash 的命令；代码会拒绝这些命令（`crates/mh-protocol/src/safety.rs`）。
- 本地 API 和插件 server 只监听 `127.0.0.1`；改变状态的操作需要 HubDeck 数据目录中 `api-token` 的 token。
- HubDeck 插件和 Stream Deck 插件都是安装到电脑上的程序，以当前用户权限运行，与其他应用一样。请安装信任的插件。
- OBS、Home Assistant、Streamlabs 的 secrets 存放在系统凭据存储中，不写入文件。
- 控制台助手通过你自己的账号运行 Claude Code；默认只修改 draft profile。开启“Let it reach further”后，每条命令和 web request 都等待你的同意。见[控制台助手](控制台助手.md)。
