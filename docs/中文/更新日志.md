# 更新日志

原文：[CHANGELOG.md](../../CHANGELOG.md)。基线 `0cbdde3`，2026-10-22。数值、已修复与已知问题均为各版发布时的上游记录。

## 0.1.9

- **Spotify 请求不再耗尽**：屏幕上有 Like 键时以前每 3 s 请求，约 2400/h，半小时后被限流；现在换歌时请求，其余每 30 s，约 160/h，日志统计调用。
- 窗口右击按键、旋钮、推杆、dial：Copy、Paste、Clear 及快捷键；页面键有 Open page。
- New profile > Ready-made 可先实体试用，Add/Back；Add 前不保存，home 不变。
- 试用时选择另一 profile 会结束试用。

## 0.1.8

- 窗口拖按键：空位移动，已有键交换；press/hold/double 一起移动，Ctrl+Z 可撤回。
- 双击页面键在窗口/实体打开，包括 Next/Previous page。
- 修复快速粘贴多键只保留最后一次、复制取到先前选中键。
- 从实体打开页面立即加载 live values，之前可能一直 `…`，直到窗口也打开该页。
- 修复插件图片 data 中空格被拒，导致 HWiNFO 选 sensor 后仍显示 logo。
- 插件键默认无 label，与 Stream Deck 一致；用户写 CPU 时提供给插件自身绘制，替代长 sensor 名，HubDeck 自动标签不再盖住插件。
- Plugins 页说明 HWiNFO 应开哪些设置。
- LHM 无读数日志说明无应答或已有 sensor，诊断可定位。

## 0.1.7

- **音乐灯光**：底座跟随 Spotify 或任意播放器节拍闪动、响度发光；可选 To the music 为全设备样式或 profile edge effect。计算 tempo、预测拍点，使灯与 kick 同时而非滞后，snare/clap 更白。Settings > Lights > Lights to the music 四预设，可设拍间暗度、起亮响度、How early，并用 8 s metronome 校准。旋钮/推杆可跟闪，默认关；仅使用此功能时监听系统声音，不录制。
- LED/图像用独立路径不再等待读控件：颜色约 35→8 ms、按键图片 35→15、dial 28→7。
- 修复音乐灯时推杆掉线；rainbow 曾达 50 色/s，超过固件承受。
- screensaver 稳定 15 fps，之前 11–13。
- app-state 键保留自有图标，用颜色表示状态。
- 新 `GET /api/leds` 返回各模块 LED 当前输出。

## 0.1.6

- LHM 0.9.5 改读数发布方式导致 CPU 温度、AMD/Intel GPU 为 `-`。现读其自有 web server，需 Options > Remote Web Server > Run；旧版方式继续可用。
- Microsoft Store 应用更新保留图标，不再 Not found on this PC，例 Spotify 1.304→1.305。
- 助手 Spotify playlist 用真实列表，不再空 Playlist 1 和索要链接；快捷键留在对应应用自己的 profile，后续修键也带应用图标。
- updater 留下 `app.bak-….exe` 仍视为同一常用应用。

## 0.1.5

- 修复 Spotify Like/playlists（#4）：2026-03 Web API 变化后 Like Forbidden，改用新 endpoints，Too Many Requests 按服务要求等待；原连接保留。
- Spotify 连接分步骤解释自有 app/Premium，打开 developer dashboard、复制地址、输入 Client ID；连后显示账号、无 Premium 则警告。
- 修复重启后 Stream Deck 插件动作无效（#5）：以前只在换 profile 时通知可见按键，Auto-switch 关时 Discord mute/deafen 等需编辑一次才生效。
- 任意模块任意连接器：官方表 88 位置外还有 42 个，多为越界布局，按连接器几何推导，窗口位置/图片方向正确，Edit layout 允许越边。
- Mochi 从按键移出 dial 再放回，保留名字与身体（Discussions #3）。

## 0.1.0（preview）

首次公开版。

- 全模块：15 keys、圆屏 dial、knobs、faders、rollers、边缘灯底座，运行中发现与定位。
- 前台切 profile、pages、press/hold/double、multi-action、modes、toggle；自选 home；分享及官方 profile 导入。
- 应用/文件/网页、hotkey、text、scroll、volume、带封面媒体、显示器亮度、系统监控、clock/timer、sound；OBS、Streamlabs、Spotify、HA、MIDI、Claude Code sessions；自有 HTTP contract 应用。
- Stream Deck 插件：5×3 keypad、dial/knobs 为 dials、右侧设置页；Settings > Plugins 约 200 开源插件一键安装。
- 无 AI tour：一个用途问题，按模块/应用立即建配置，实体逐步讲解，当前控件闪烁，每部分保留/跳过，采用前不改原内容；允许统计后次日建议替换未用控件。
- 账号内 Claude Code 助手给整套草图或逐控件选项 gallery。
- 全设备统一灯光风格，响应通话/静音/agent 等待。
- 窗口围绕控件用途重建：选键后 What should it do? 和他人用例，或动作拖放；使用常见名称 Open、Multimedia、Text、Multi action、Pages；新页加 Previous/Next，上一页加 Next，无入口页面会说明；实时显示值/封面/时钟。
- 按下短描边，失败红角到下次成功；app/scene/source/device/entity 字段改列表。
- Updates 可回退，Plugins 可独立启停，CPU 超 20% 提示。
- guard 在异常时交回设备并重启，窗口显示 crash report；单实例驱动设备。
- Reduce motion 初次继承系统，设备/窗口不闪烁。
- Windows 10/11、Apple silicon/Intel macOS；Mac 支持 calls、应用 profile、CPU/GPU 温度、内置屏亮度、14.2+ 分应用音量，首次申请 System Audio Recording。

发布前 Windows 10 release 测量，最忙配置 22 动画+Mochi：单核平均 9.4%，五分钟内存 59→62 MB，按键 16 pictures/s；三次重启各模块 6 s 恢复；托盘静止约 3%/40 MB；窗口 162 fps 无慢帧；安装包 9.0 MB、安装后 21.2 MB，cargo audit/pnpm audit 无告警。

- 窗口动画约 8 fps，实体 15+；开窗口 WebView2 约 300–350 MB，关闭后 HubDeck 约 70 MB。
- Mac 重启后按键/dial 偶不收图，自动尝试重启模块，取下重装有帮助。
- Mac 未 notarised，首次 System Settings > Privacy & Security > Open Anyway；Windows 安装器无代码签名，SmartScreen More info > Run anyway。
- Elgato 复制保护插件不运行，作者自供文件可用。
- macOS 12–14.1 无分应用音量，系统/播放器可用。
