# 为游戏设置控制台

原文：[docs/GAMES-SETUP.md](../GAMES-SETUP.md)。基线 `0cbdde3`，2026-10-22。

最快方法：加入游戏预设，开始玩，再调整不合适的地方。以下全部在 HubDeck 窗口内进行，无需往游戏中安装内容。

## 1. 从预设开始

Profile tabs > **+** > *From a preset* 列出 Diablo IV、Baldur's Gate 3、Counter-Strike 2、Valorant、Fortnite、Minecraft、League of Legends，以及供其他游戏使用的 *Game action bar*。预设采用默认键位、游戏图标，并把游戏、Discord 和音乐音量分配给 dial、旋钮、推杆。游戏在前台时自动切入，离开后返回 home profile。

没有对应游戏？选择 *Game action bar* 或 *Empty profile*，再在 profile 面板关联游戏：点活动 tab > 应用列表，在游戏运行时选择它。

## 2. 调整按键

- **游戏改过键位？** 在设备示意图选中按键，右侧面板 *Keys* 旁点 *Record*，按游戏实际使用的键。
- **保留 Send as: For games**：游戏读取键盘的方式不同，此模式发送硬件键码并短暂保持。漏按时把 *Hold (ms)* 提高到 50–80；游戏若以管理员运行，HubDeck 也需管理员权限。
- **同时或顺序发送多个键**，如 combo 或购买序列：选择 *Multi action* 加步骤，或 *Record keys* 录入序列。
- **超过 15 键？** 在 *Key pages* 旁点 + 加页面，并在主页放 *Go to page*。
- **旋转操作**：旋钮或 dial 可各方向发送一个快捷键，设置 *Hotkey* 的 *Turn clockwise* / *counter-clockwise*，例如缩放或切武器。

## 3. 自备图片

- **图标**：外观编辑器选 *Interface*、*Games*（300 个 game-icons.net 图标，可搜 sword、potion、map）或已装 icon pack。
- **图片**：*Choose picture* 接受 PNG、JPG、WebP、SVG、animated GIF，填满按键，标签在上层。游戏技能图标截图适合自用，不要分享游戏素材。
- **图标包**：图标 tab 末尾 + 可安装含 `manifest.json` 的 zip/文件夹，或 `.streamDeckIconPack`。使用有权使用的素材。
- **风格和颜色**：Flat、Gradient、Glass、Outline 及颜色预设控制按键框，标签与文字颜色在上层。

## 4. 分享

Profile panel > *Export* > *HubDeck profile with its pictures* 导出包含全部图片的 `.hubdeck`。朋友用 *Import* 导入；也可按[分享配置](分享配置.md)提交 gallery。分享前将无权传播的游戏素材替换为可分享图标。
