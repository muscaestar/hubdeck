# 设计好用的 HubDeck profile

原文：[docs/PROFILE-DESIGN.md](../PROFILE-DESIGN.md)。基线 `0cbdde3`，2026-10-22。

这些规则面向手工配置者，以及通过 MCP server 构建配置的 AI 助手。见 [MCP](MCP工具.md)，`design_guide` tool 提供本文件。硬件包括 15 屏幕按键、可转可按圆屏 dial、三个 LED 环旋钮、五个 LED 推杆、双滚轮和底座边缘灯。

## 1. 从用户用途开始

- 询问或推断用途：Photoshop、OBS 等应用，直播、会议、游戏等活动，或日常桌面。使用简短用途命名，如 Photoshop、Streaming。
- 根据 `list_modules` 已有模块配置。不存在模块上的功能不可见，重要功能应放在可触及的位置；其他模块也可填，未来连接即生效。
- 应用 profile 用 `apps`（如 `Photoshop.exe`）关联，自动切换。
- 只填有用且核实的应用、媒体、音量、`list_shortcuts` 快捷键；不要猜快捷键或凑功能，宁可留空。

## 2. 布局：常用动作占易触及位置

- `keys.0`–`keys.14`，每行 5、共 3 行，从左上开始。中行和左两列易盲按，放最常用 3–5 个动作。
- 按任务分块，例如上行导航/场景，中行主工具，下行开关与低频项。跨 profile 同功能同位置；mute 固定位置，页面返回固定 `keys.14`。
- 成对按阅读顺序相邻：上一项/下一项、undo/redo、缩小/放大。
- 超过 15 项按组用 `add_page`，如 Tools、Scenes；主页有入口，子页 `keys.14` 返回。只用一层。

## 3. 转、滑、按、长按各尽其用

- 连续值放旋转/滑动控件，如音量、笔刷、缩放、滚动、时间轴、亮度。推杆适合设定后保持的应用/麦克风音量；旋钮和 dial 适合微调；滚轮适合 scrolling/jogging。
- 按键一个按下一个结果。
- `:hold` 用于删除、结束直播、关闭应用等破坏性或罕见动作，或繁忙按键的第二功能。`:double` 不延迟其他操作，但用户易忘，应少用且标明。
- 旋钮/dial 用 `core.modes` 承载 2–4 个相关旋转功能，按下切下一项，勿堆杂项。
- record、stream、mute 等持续状态动作要有开启外观 `lookOn`，或默认红色版本。

## 4. 外观：统一、对比清楚、文字简短

- 标签每行不超过 10 字符、一两行，用动词或名词，如 Record、Next、Mic。不要标点、Toggle 或每键重复应用名。
- 同 profile 一套图标家族：内置线图、游戏 `game:<name>` 或一致风格自绘图；同一行不要混线图和照片。
- 默认 house look：石墨色按键、分组低饱和色图标、白标签；draft 默认套用。用户要求时才换其他背景。profile 统一一个 accent，用于 profile 色和边缘灯。
- 文本/图标与背景至少 4.5:1 contrast，用 `preview_control` 检查，亮背景用深色字。
- 默认 flat；glass、gradient、outline 仅按用户要求。
- dial 圆屏 240×240，内容保持中央 170 px 内。

## 5. 灯光表达含义

- 所有地方统一：红=live 或 muted，橙=需要关注，绿=ok/ready，profile 色=常态；红色不作装饰。
- 音量旋钮/推杆用 `ledLevel: true` 表达数值。
- 底座边缘常态平静显示 profile 色，breathing/strobe 仅用于录制或 agent 等待等关注状态。全设备灯光已有麦克风、live、agent、timer 响应，不要以恒定效果争用。
- 亮度由用户决定，未经询问不改全设备设置。

## 6. 图片与动画

- 自绘 SVG 适合 72×72 / 240×240，清晰且小；简单形状、调色板 2–3 色、4–6 px 边距、线宽至少 2 px、不用小字。
- 480×272 整面板图可营造氛围或 dashboard，按键仍执行动作。
- 动画轻微且有目的，如录制键脉动、dial 慢闪。最多 15 fps，8–12 足够，8–30 帧，末帧自然接首帧。每屏幕区域最多一个动画控件，不要每键都动。
- 网络图片需使用权；优先自绘或用户文件。游戏封面从用户 launcher 获取并留在本机。

## 7. 反馈提供信息

- 变化应回答用户的问题，如是否 live、麦克风静音、agent 需要我；没有人会问的内容不显示。
- 值变化时短暂显示，dial 已默认显示 1.5 s，不要一直占屏。

## 8. 收尾

- 逐个控件检查：功能单一明确、位置符合手部预期、标签可读、颜色能表分组。
- 用 `preview_control` 看重要按键和 dial，修正可读性。
- 一句话告诉用户特别之处、可改项，以及替换时已留备份；窗口和设备会显示具体控件。
- 替换/删除已有 profile、page、全设备设置前先询问。
