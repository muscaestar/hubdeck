# 源码研究三：引擎、配置、动作与渲染

最后更新：2026-10-22。基线 `0cbdde3`，静态源码研究。文件均在 `app/src-tauri/src/engine/`，本篇的源码链接可直接跳转。测试名称说明仓库已有覆盖，不表示本轮执行。

## 核心 `mod.rs`

[源码](../../app/src-tauri/src/engine/mod.rs)。4343 行的主协调模块，不只是声明子模块。Engine 包含 AppHandle、data_dir、message sender 和 Shared；Worker 独占 Executor、Renderer、手势、定时动作、图片/LED 缓存、媒体/集成状态、宠物/游戏等运行状态。

`Engine::start` 初始化图片、常用应用、usage/taste/presses/nudge、已装应用、daily backup；加载 Store，缺配置则建立 everyday desk；设字体、助手权限、语言；创建 Worker，然后启动前台、媒体、系统监控和各集成。插件启动后主动发 ProfilesChanged，解决启动时没有 willAppear 的问题。

### 输入路线

`Msg::Input → on_input → fire → run_binding → Executor::run / 特殊动作处理`。

`on_input` 按状态先处理唤醒、screensaver、calibration、arcade、引导高亮、按下描边、usage、draft 比较、实体问答，再走普通 profile。息屏或 saver 的首次触碰只唤醒，不执行动作。问题显示期间 key/dial 用于回答/取消。

普通输入先按 page 转 id，通知 API，再走按压/旋转/滑动。MIDI note、插件、while-held 动作保留 release；PTT/vJoy button 不等 hold/double。普通手势由 Gestures 判定；旋转可加速，推杆经 filter。**API 的 input 并非一定覆盖所有被前置模式截获的触碰**，前面的 return 会跳过普通 API 广播，复用时需要区分原始输入与业务输入。

### Worker loop 与输出

默认 timeout tick 40 ms，arcade 25 ms，按动画 deadline、music 20 ms、saver 66 ms、待发图动态缩短。把队列已有消息取成 batch，同控件旋转合并，防追放旧数值；按时处理长按/双击和 scheduled steps，异步集成结果以 Msg 回流。

`PictureSender` 每屏一个 worker，只有一个待发 slot，新图覆盖旧待发图，适合最新状态显示；这不是逐帧可靠送达队列。HID 失败记模块，下个 engine tick 清 sent cache 重绘。LedSender 另有 pending/失败追踪。图片与 LED 发送不在 UI thread，部分 feature/backlight 仍在 engine 路径，需要注意耗时。

dirty flag、已发图片/LED 比较、每秒 state poll、4 s 配置目录 stamp 检查，降低重复工作。dial 最短 36 ms，feedback 保留 1500 ms，按键 flash 160 ms。窗口镜像经 Tauri Channel 而非高频全局 event，dial 镜像最密 125 ms；每种最多四个 listener，失败剔除，减少 reload 泄漏。

### Profile 切换与模式

home 是用户手选后的回退；前台匹配临时接管，离开再回 home。app+title 比 app 单独匹配更具体。pinned、call_hold、trying/draft_compare 会影响切换。`try_profile` 保存原 active/home/auto_app，取消恢复；use_draft 有 `versionOf` 时备份后覆盖原 profile 内容并保留原名字/应用关联。

按键分页只改变 keys，dial/knobs/faders/rollers 全页共享。core.multi 的 delay 累计为 scheduled 队列；conditions 在执行时判断，不能用 sleep 堵主 worker。

现有 tests 涵盖合并旋转、profile 接管与归还、draft 新版本、delay 累积、slot table、高亮跨页、动画跳帧、LED 顺序、校准。

## 配置 `profile.rs`

[源码](../../app/src-tauri/src/engine/profile.rs)。Profile version=1；绑定到控件类型而非 serial，便于共享。主要类型：

| 类型 | 持久语义 |
|---|---|
| `Look` | label/icon/bg/fg/icon_color、LED/level/effect/speed、style/image/fit/note |
| `Binding` | action、params、look、lookOn、accel、swapTurns |
| `Profile` | id/name/apps、controls、pages、edge/effect/speed、panel/color、inBar、assistant、versionOf、switchIn |
| `Settings` | active/fallback、pin/auto、panel geometry/rotation、屏幕、服务地址、shared profiles、draft/ready、助手、语言、灯光、统计等 |
| `Store` | 载入/保存 settings 和 profiles，内存 BTreeMap |

Look 的 face/pressed/failed 属临时绘制状态，不写回。Binding::look_for 在 on state 切显式 lookOn 或派生配色/图标；未知插件保留 label 并提示不可用。

app_stem 统一跨平台名、exe/app 后缀、版本号及别名；app_match 支持 `exe: title` 与 `*: title`，标题子串大小写归一。匹配分数 2 为带标题、1 为应用，切换选择逻辑在 engine。

Store 先写临时文件+rename，再更新 map；坏 profile 单独 warning 并留磁盘，不使整体启动失败。safe_file_name 把导入 id 的非法字符变 `_`，并非要求所有导入 id 原本是 UUID。fallback_id 修复失效引用，先选无 apps，再选第一份。

注意 `version` 字段存在不等于已经实现完整多版本迁移器；当前主要依赖 serde defaults。delete_profile 清 active/fallback/drafts/ready，并保存 settings。shared folder 外部变化由 engine 定期 reload。

## 动作与输入逐模块

| 模块 | 职责、入口与扩展注意 |
|---|---|
| [actions.rs](../../app/src-tauri/src/engine/actions.rs) | `ActionDef/InputKind/ParamKind/ParamDef` 描述动作与表单。catalog 是主要内置表，all 合并插件，find 查 action。输入有 Press/Turn/Slide，参数支持 App/Target/Named/Steps/Modes 等。新增动作先声明 inputs/default/help/when，再实现 executor 或 worker；UI 与 API 依此校验。steps/modes 会清洗嵌套动作，测试覆盖 catalog 一致性、数值字符串、PTT、multi/modes |
| [exec.rs](../../app/src-tauri/src/engine/exec.rs) | `Executor::run` 将 Binding+InputEvent 变 Outcome；profile/page/brightness/timer/lighting 等副作用回交 worker，OS/服务请求走专用实现。keyboard 把 Enigo 放其线程，游戏 scan code 可保持。run_command 分 command/args/folder/hidden；http_request 用 method/url/body/headers，设超时。不是所有 action 都在一个 match 完成，插件/modes/live 等在 worker 另分流 |
| [gestures.rs](../../app/src-tauri/src/engine/gestures.rs) | Down/Held/Released/Doubled 状态机。纯 tap 无附加绑定时 down 即触发；绑定 hold 后短按等 release；有 double 时短按还要等窗口。hold 500 ms，double 300 ms。与 README“double 不延迟”不完全一致，按实际绑定解释。换页/配置 clear |
| [hotkey.rs](../../app/src-tauri/src/engine/hotkey.rs) | Ctrl+Shift+F13 parser；修饰先按、逆序释放，特殊键 Windows VK/mac key code 分支。Windows For games 走 hardware scancode 并保持，其他平台回退 send，不应声称所有平台均同一游戏注入实现 |
| [recorder.rs](../../app/src-tauri/src/engine/recorder.rs) | Windows low-level keyboard hook，只录用户而非注入事件；按时间转换 hotkey+delay，过滤纯 modifier/自动重复。最多 120 s、2000 events、单步 delay 最大 10 s。start/stop 管线程；其他平台能力需按 cfg，tests 覆盖 modifier 合成和键名 |
| [check.rs](../../app/src-tauri/src/engine/check.rs) | 导入后的本机依赖诊断，Env 含 app/path/image/audio/MIDI/OBS/HA 等。needs 先判断是否值得枚举音频/MIDI；issues 返回控制 id 和可修信息。shell:AppsFolder 是协议目标，不能当不存在文件。与 API 保存前 schema check、助手 guard 是不同层 |
| [timer.rs](../../app/src-tauri/src/engine/timer.rs) | Timer 持 total/left/running_since/rang；支持 start/pause/reset/增分钟，最大 359999 s，标签向上取整避免提前 0:00。Pomodoro 分 focus/short/long 和轮次，结束等按下；ClockState 另管秒表和视图。Instant 管时长，chrono 管日历，音效另线程。按 profile/control 在 worker 中隔离 |

## 自己扩展时的最小改动路径

新增业务动作通常四处：actions schema、exec 或 worker 的行为、状态反馈/渲染、前端参数呈现。新增持久字段先加 serde default，明确旧版缺字段语义，并验证 shared folder、导入导出、draft/versionOf 和备份。

性能首先检查消息频率、重复重绘、JPEG 编码和 HID backlog；不要只给 UI 降帧而漏掉设备或独立 worker。文档中的历史速度只用于定位设计原因，不能代替本机 benchmark。
