# 源码研究四：系统、音频与外部服务

最后更新：2026-10-22。基线 `0cbdde3`。以下为源码接口、线程、状态和失败路径研究，不表示已连接真实服务。

## 统一集成方式

多数服务使用 OnceLock 保存 sender，独立 worker 持网络连接或 OS 资源。动作发 Request；worker 回送 `Msg::IntegrationState`、`IntegrationValue`、`IntegrationFeedback`、`IntegrationError`。engine 据此重绘与变灯；只有请求已发送，不代表远端已执行成功。列表缓存由 names 提供，缺少缓存与“已连接但空列表”是不同状态。

新集成应先定义请求、状态 key 与可列举名称，再做动作 schema、worker 和 engine 可见性需求。需要长连接或慢请求时不要塞进输入主循环。

### macOS 原生音频

[`macos/appvolume.m`](../../app/src-tauri/src/macos/appvolume.m) 在 14.2+ 使用 CATapDescription、aggregate device、AudioDeviceIOProc，tap 原进程并使其原通路静音，回调乘 atomic gain 再播放。不是改 app 内部 slider，也不保存录音。返回 full gain 时移除 tap；`mh_appvol_reset` 在 HubDeck 退出时解除所有。

按 bundle/app 名匹配含 helper 的音频进程，`others` 用排除集；`mh_audio_playing` 返回需 Rust 通过 `mh_free` 释放的 C 字串。每次从 Rust 线程进入都要有 autoreleasepool，避免连续转音量累积临时 Foundation 对象。错误码区分无声音、OS 太旧、权限、无输出、设备启动失败。

修改此处要核对音频设备切换、app 重启、多 helper、HubDeck 崩溃后的音频恢复，Windows 测试不能覆盖 macOS callback/ARC/实时音频行为。

## 虚拟手柄 `vjoy.rs`

[源码](../../app/src-tauri/src/engine/vjoy.rs)。把 Driver trait 与 `Joystick<D>` 逻辑分开，真实 Windows DLL 和 fake tests 共用轴/按钮/hat 逻辑。首次动作才加载 `vJoyInterface.dll`，从安装目录/注册信息寻找，失败缓存 10 s，未安装不会每次输入反复扫描。

- device id 1–16 懒 acquire，保存 owned 集合；首次 acquire 清对应轴缓存，初始旋钮轴位置为 0.5。
- 轴内部统一 0–1，to_raw 映射 driver min/max。推杆绝对值 /100，旋钮 delta×step/100，与同轴推杆共享最近值；press 可以 center/zero/max/nothing。
- button 1–128，按下保持/松开；旋转产生待执行 taps，时间上分 down/up，避免一帧看不到；队列 MAX_QUEUED=12，实际 TAP_DOWN 常量约 40 ms，不能无限积压旋转旧命令。
- hat 支持 continuous 以 1/100°，或 four-way，斜向在四向设备明确报错。
- release_all 复位、归还所有 owned device、清轴值，接入 pause/sleep/exit。

tests 用 fake driver 覆盖 acquire、axis clamp、increment、hat、缺轴/按钮、输入动作；不证明 vJoy driver 在我们的 Windows 配置可装或游戏能识别。赛车开发先复用这一层，不在 UI 直接调 DLL。

## 音乐灯 `beat.rs`

[源码](../../app/src-tauri/src/engine/beat.rs)。Windows WASAPI loopback，仅在灯光需求存在时启动采样，不记录/上传音频。DSP 与 capture 分层：约 10 ms mono block，低频能量找 kick，RMS 平滑算响度，中高频突变找 snare/clap；1024 sample Hann FFT 的正 spectral flux 进入最多 600 block 历史。

tempo 检测在约 300–750 ms lag（80–200 BPM）找周期，倾向 120 BPM，要求约 4 s 数据；每 50 blocks 更新，confidence 和 stands_out 门限带 hysteresis，降低噪声乱跳。glow 用已确认 period/anchor 预测拍点，lead 提前量默认 20 ms；tuning 控 dim/from/white，另有 8 s metronome wav 校准。预测可能在弱音乐段延续，不是所有曲种都能稳定锁拍，threshold 来源于作者样本。

单元测试涵盖合成音频、节拍、噪声和 envelope 等；原设备链路延迟、音频输出切换需单独测试。别把用户调灯亮度的 100 ms rainbow tick 与 music 的 20 ms step 混为一谈。

## 应用发现与图标

- [apps.rs](../../app/src-tauri/src/engine/apps.rs)：打开窗口与最近前台 app，最多 40，apps.json 缓存 exe/path/last title；忽略系统 host，读 version description/Finder 等友好名，合并当前发声 app。新 app 才写磁盘，减少频繁前台变化 I/O。
- [appicon.rs](../../app/src-tauri/src/engine/appicon.rs)：提取 128 px Windows HICON/bitmap 或 macOS NSWorkspace/Finder 图标，缓存 PNG；macOS 线程 autorelease pool 和位图 alpha 不能省。文件头“其他系统未实现”已过时，实际有 macOS 分支。
- [installed.rs](../../app/src-tauri/src/engine/installed.rs)：Start menu 用户/全局快捷方式、Microsoft Store shell:AppsFolder、mac Applications，Steam/Epic/GOG。cache version 3，按需 blocking scan/Refresh；cover 只读本机 launcher cache，mark local-only，不能随共享包传播。游戏的实际 exe 可能由 launcher 派生，install folder 用于运行进程匹配；UWP 图标目录版本会变，store_logo 重新选高质量资源。

## 修改与验收重点

优先用现有 Request/Msg/name 层加功能，保留每个服务独立断线重连，不把网络失败升级为整个设备不可用。认证、真实服务状态、默认输出切换、睡眠恢复、平台权限需现场验收；本轮记录的是实现位置和静态行为。
