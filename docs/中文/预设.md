# 预设：人们用 MasterHUB 做什么

原文：[docs/PRESETS.md](../PRESETS.md)。基线 `0cbdde3`，2026-10-22。市场数据和功能状态为原作者 2026-10 的记录。

preset 是某应用/工作流的现成 profile，适配连接的 keys、faders、knobs、rollers、dial。本目录用于决定先实现哪些预设和插件。

## 调查所得（2026-10）

- Cooler Master 宣传直播 OBS/Streamlabs/Twitch、Adobe Photoshop/Illustrator/Premiere Pro、无需菜单改设置的游戏用途、scrub timeline 剪辑。Computex 2023 的 Photo/Video 套装未发货。
- 官方只交付 Default 和 Photoshop 两模板、各应用动作（OBS、Streamlabs、Twitch、Discord、Adobe 快捷键、系统；Voicemod 只有 UI 文字无动作）、`.mhz` 导入导出。承诺 marketplace 未出现。详见[官方应用对比](官方应用对比.md)，2026-10-11 修正。
- 评测者用推杆混音、按键 OBS 场景和截图、dial 音量、滚轮/旋钮滚动和 undo/redo、Steam/Discord launcher、dial CPU/GPU 温度、RPG action bar；提出 Star Citizen、Flight Simulator、Helldivers 2 用途。
- 主要抱怨：推杆只控设备亮度/系统音量/OBS/Streamlabs 四类；hotkey 只能实键录入、无 F13–F24；LED 仅模块级；dial 仅时钟、CPU/GPU、图片；缺预设和市场；启动丢配置；停止更新。
- 同类 Stream Deck、Logitech MX Creative Console、Monogram、Razer、TourBox 采用 Adobe/Resolve/Lightroom/OBS 现成配置、前台自动切换加通用回退、文件或市场分享；Resolve 和飞行 autopilot 付费配置受欢迎。

## Stream Deck 用户安装什么（2026-10-13）

按公开 marketplace `mp-gateway.elgato.com/products?extension=plugins&ordering=-download_count` 下载排序，1530 plugins、995 profiles，原作者实际统计：

1. **分应用音量/音频**：总榜第一 Volume Controller（1），Audio Switcher（10）、Audio Mute（15）、Discord Volume Mixer（22）、Audio Mixer（35）、VoiceMeeter（47）、Wave Link、GoXLR。MasterHUB 原生旋钮推杆适合，最好的初体验。
2. **直播**：OBS Studio（2）、Twitch（7）、YouTube（8）、OBS Tools、Twitch Tools、Streamlabs（18、30）、TikTok LIVE Studio、计数器/计时、VTube Studio、Camera Hub。
3. **语音/通话**：Discord（3）、Voicemod（4）、Zoom；profile 榜 Discord（2）、Zoom（4）、Teams（6）。
4. **音乐**：Spotify Integration（5）、Spotify（9）、Essentials for Spotify、YouTube Music、VLC。
5. **Windows 工具/快捷键**：Control Center（6）、Win Tools、SuperMacro、窗口移动、Advanced Launcher；profile 有 Windows 11 Essentials（3）、Excel、Word、Chrome、Mac shortcuts、PowerPoint、VS Code。
6. **实时信息**：Clocks（13）、Weather（17）、Speed Test、System Vitals、GPU Metrics、Battery、World Time。
7. **游戏**：下载最多 profile 是 Helldivers 2 stratagems；还有 ShadowPlay、Xbox Game Bar 片段、Star Citizen、WoW、Cyberpunk 2077、Arc Raiders。
8. **家居/灯光**：Home Assistant（28）、Philips Hue（36）、Govee、iCUE。
9. **趣味**：Sound Deck/Soundpad/随机音效、emoji 键盘、Tamagotchi；AI prompt profile 较小众，约 profile 榜 30。

因此 tour 按常见用途而非某一个人配置排序，只显示适合此人的 stop：安装 OBS/Streamlabs/直播应用才讲直播；找到游戏才讲游戏；有 Claude Code 才讲 agent，均填用户自己的应用。

## masterhub 的预设机制

1. 内置、免费、可编辑，每项都是普通 profile。
2. 感知布局，按模块类型声明 slot，填已连接部分，缺模块不破坏配置。
3. 指定所属应用，跟随前台，通用 profile 回退。
4. 单文件导出导入，未来社区 gallery 先用 GitHub repo。
5. 预设只排列动作，动作由插件提供，新集成带来新预设。

## 对官方软件抱怨的核心修复

- 推杆和旋钮可控任意数值目标，如应用音量、MIDI CC、插件参数。
- hotkey 列表含 F13–F24、媒体键，录制可选。
- 每控件 LED，颜色跟随 mute 红橙或数值渐变。
- dial/整面板由插件绘制，任意文本、仪表、图表、图像、动画。
- 原子保存，启动不丢配置，可导出可读文件。

## 剪辑面板（2026-10-12 实现）

原 Video editing 混合 Premiere/Resolve；现在每 editor 一套，自动跟随，Profile for an app 自动选用，布局一致：

- dial shuttle：L 向前、J 向后，反复按加速，快速旋转有 turn acceleration，慢转正常速度；按下播放/暂停。CapCut 无文档化 J/K/L，改 Shift+箭头跳转。
- roller 1 逐帧、roller 2 时间轴缩放；knob 1 大跳、knob 2 上/下 edit point、knob 3 系统音量。
- 按键：四个 editor 工具、undo（hold=redo）、in/out、marker、上/下 edit、reverse、stop、play、forward、save（有默认键则 hold=export）。
- 推杆：system、editor、Chrome、Spotify、Discord 音量。

## Sim panel（2026-10-12 实现）

Windows vJoy 虚拟 joystick，用户自行装 driver。Keys 1–15 持续 buttons 1–15；五推杆为 Z throttle、Rx mixture、Ry prop、Slider flaps、Dial trim；dial 精调同一 trim；knobs 为 X/Y/Rz；滚轮点按 16/17、18/19。任何读 joystick 的 MSFS、DCS、X-Plane、iRacing、Star Citizen 等可绑定。

自动关联 `FlightSimulator.exe`、`FlightSimulator2024.exe`、`DCS.exe`、`X-Plane.exe`、`iRacingSim64DX11.exe`、`StarCitizen.exe`，见[模拟器面板](模拟器面板.md)。
