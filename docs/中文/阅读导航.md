## 术语约定

| 术语 | 本文档采用的含义 |
|---|---|
| deck / 控制台 | 实体 MasterHUB，或由 profile 定义的整套控件安排，按上下文区分 |
| base / 底座 | 承载模块的 USB hub 与边缘灯模块 |
| module / 模块 | 按键、dial、knobs、faders、rollers 等硬件，或代码模块，按上下文说明 |
| dial | 带圆屏、可按下的大旋钮；保留英文，区别于三旋钮 knobs |
| knob / 旋钮 | 三旋钮模块的单个旋钮 |
| fader / 推杆 | 五推杆模块的单个线性控件 |
| roller / 滚轮 | 双滚轮模块的单个控件 |
| profile / 配置 | 保存绑定、外观、页面、应用关联的一套配置，标识符不翻译 |
| binding / 绑定 | 一个控件与动作、参数、外观的关联 |
| action / 动作 | 输入事件触发的功能 |
| look / 外观 | 标签、图标、图片、颜色、样式等配置 |
| report | HID 数据报告，保留 Input/Output/Feature 与字节值 |
| software mode / hardware mode | 软件接管/硬件内置模式；原文术语保留 |
| draft / 草稿 | 助手等编辑时使用的未正式采用配置 |
| engine / 引擎 | 处理输入、动作、状态、绘制、集成的 Rust 应用层 |
| 原作者实测 | 上游文档记录的实验，不表示此 fork 已复测 |

## 翻译边界与阅读提示

英文原文与授权原件保留。产品名、API、类型名、命令、路径、URL、JSON 字段保留英文；界面操作名通常保留英文，便于与当前应用对照。代码示例按原文保留，代码外解释使用中文。

译文不擅自把 planned、partial、未验证改成可用。原文中历史描述、矛盾与失效引用会在源码研究中单独记录，避免翻译时混入未说明的修订。网站、工作流、模板和运行时资源作为工程模块研究；运行时提示词与第三方署名/许可另有中文阅读副本。
