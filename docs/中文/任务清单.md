# 中文翻译与源码研究任务清单

最后更新：2026-10-22

基线：`0cbdde3`（上游 v0.1.9）。目标是逐篇翻译仓库文档，并通过阅读实际源码为每个代码模块留下可追溯的中文说明。最终交付由主人验收。

## 工作约定

- 英文原文保留，中文译本集中在本目录；API、标识符、命令、文件路径、产品名保留英文。
- 逐节翻译，保留表格、数值、限制、日期、代码示例与引用。原文的实验结果属于原作者记录，不代表已在本机复测。
- LICENSE、第三方授权与署名原件保留；另提供中文对照。运行时使用的 `assistant-rules.txt` 只提供中文阅读副本，不修改提示词。
- 源码研究分别记录职责、入口、数据流、依赖、状态与错误处理、扩展位置、现有测试和待验证事项。
- 源码阅读与实机验证分别记录。文档任务不运行会接管设备的示例或测试。
