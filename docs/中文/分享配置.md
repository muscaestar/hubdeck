# 分享 profile

原文：[docs/SHARING.md](../SHARING.md)。基线 `0cbdde3`，2026-10-22。

HubDeck profile 可打包为单文件，也可通过应用内公开 gallery 分享：Profile tabs > `+` > Browse shared profiles。

## 包格式：`.hubdeck`

`.hubdeck` 是 zip：

```text
profile.json          与 HubDeck 保存格式相同的 profile
images/<name>         profile 使用的每张图片
```

- `profile.json` 对应 `app/src-tauri/src/engine/profile.rs` 的 `Profile`，`version` 1。原 id 无关紧要：导入总生成新 id，不覆盖已有配置。
- `images/` 包含所有页面和手势的 `look.image`、开启外观 `lookOn.image`、整面板 `panel: { kind: "picture", image }`。名字与 JSON 一致，只能字母、数字、`.`、`-`、`_`，不含目录。支持 PNG、JPG、GIF（含动画）、WebP、SVG。
- 导入时按图片内容生成名字，避免同名不同图冲突，并更新 profile 引用。图片缺失或不可读则删除该 look 的 image，保留 icon 和 label。
- 每图最大 15 MB、解包总量 100 MB、1000 文件。其他 zip 内容忽略。

导出：Profile panel > Export，类型 HubDeck profile with its pictures。Settings only 仍导出便于手改的纯 JSON，不含图片。

导入：Profile panel > Import 支持 `.hubdeck`、HubDeck `.json`、官方 `.mhz`。

Play sound 的声音、Open app, file or website 的程序均为作者本机路径，不打包，导入后检查这些按键。

## Gallery

公开仓库为 `Przemotar/hubdeck-profiles`，应用从 UI 线程之外、5 s timeout 读取：

```
https://raw.githubusercontent.com/Przemotar/hubdeck-profiles/main/index.json
```

无法访问显示 The gallery is not online yet。只从该仓库 `https://raw.githubusercontent.com/Przemotar/hubdeck-profiles/...` 或 `https://github.com/Przemotar/hubdeck-profiles/...` 下载包。

### `index.json`

```json
{
  "version": 1,
  "profiles": [
    {
      "id": "obs-streaming",
      "name": "OBS streaming",
      "author": "Przemotar",
      "description": "Scenes, record, stream and replay on the keys with live state; mic level on the dial.",
      "kinds": ["keys", "dial", "faders"],
      "tags": ["streaming", "obs"],
      "preview": "https://raw.githubusercontent.com/Przemotar/hubdeck-profiles/main/obs-streaming/preview.png",
      "package": "https://raw.githubusercontent.com/Przemotar/hubdeck-profiles/main/obs-streaming/obs-streaming.hubdeck",
      "version": "1.0"
    }
  ]
}
```

| 字段 | 必填 | 含义 |
|---|---|---|
| `id` | 是 | 唯一、小写、单词间 `-`，也是文件夹名 |
| `name` | 是 | 卡片标题 |
| `author` | 否 | 姓名或 GitHub handle |
| `description` | 否 | 一两句描述用途及功能分布 |
| `kinds` | 否 | `keys`、`dial`、`knobs`、`faders`、`rollers`；没有的模块在卡片变灰 |
| `tags` | 否 | streaming、photo、music 等搜索词 |
| `preview` | 否 | profile 的设备截图，PNG/JPG，约 800×450 |
| `package` | 是 | 仓库内 `.hubdeck` 文件 |
| `version` | 否 | 自己的版本，如 1.1 |

未知字段忽略，便于扩展格式。

## 提交 profile

1. Profile panel > Export > HubDeck profile with its pictures，命名不含私密信息（路径、账号、token；HubDeck 不把密码/token 放进 profile）。
2. 可选设备截图，命名 `preview.png`。
3. Fork `Przemotar/hubdeck-profiles`，添加 `<id>/`，放 `<id>.hubdeck` 和可选截图；在 `index.json` 添加条目。
4. 开 pull request 说明功能与适用应用。

reviewer 检查可导入性、图片为自己所有或允许分享、按键没有执行标签看不出的程序或命令。
