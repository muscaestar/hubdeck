# 状态面板与实时值

原文：[docs/STATUS-BOARD.md](../STATUS-BOARD.md)。基线 `0cbdde3`，2026-10-22。

按键与 dial 可自动刷新网页返回值、Home Assistant sensor、命令输出、天气、下个日历事件。阈值让按键变橙或红；带最大值的 dial 数字显示为环。Status board 预设放置一组此类控件。

## Live value 动作

添加到按键或 dial，位于 System 组，选择来源：

| 来源 | 字段 | 显示 |
|---|---|---|
| A web address | Address（`https://...`）、Value at（JSON path，如 `data.items.0.price`、`data.items[0].price`；空为纯文本）、可选 Token | 指定路径的数字或文本 |
| The weather | Place 城市搜索、°C/°F | 整数温度和 Clear/Cloudy/Rain/Snow/Storm 等短词 |
| Next calendar event | 日历私密 ICS 地址 | 距下项时间，如 30 min、4 h、Fri，以及标题；进行中为 Now |
| Home Assistant | Entity，如 `sensor.living_room_temperature` | 含单位的 entity state |
| A command | Command line | 输出第一行 |

通用字段：

- **Refresh every (s)**：最短 5 s；天气 10 min；日历每 5 min 下载，期间自行倒数。
- **Before / After the value, Decimals**：如 `$` + `41250` + ` USD`；decimals=-1 保留原值，天气未另设小数则整数。
- **Warning at / Alert at, Worse when**：达到 warning 为橙，alert 为红；电量、剩余空间用 Lower；空表示不启用。
- **Maximum**：dial 按最大值绘制环，如 CPU 100、风扇 2000 RPM。
- **Press opens**：按下打开的页面或文件，空则立即刷新。
- 按键自身 label 成为值下的小字。

缺少配置显示 Set up；待首次返回为 `…`；读取失败为 `–` 和说明，日志有原因；命令待允许显示 Allow?。

### Tokens

网页 token 从 Windows Credential Manager / macOS Keychain 读取，条目为 `HubDeck` / `live:<name>`。在 Token 填写后 Save，profile 只存条目名，导出分享不带 token；请求以 `Authorization: Bearer <token>` 发送。

### 命令

共享 profile 不得自行运行程序。只有用户在本机允许后执行；显示 Allow?，按下批准该精确命令行，记录在 `<app data>/live-commands.json`，删除相应行可撤回。Windows 用 `cmd /C`、macOS 用 `sh -c`，无窗口、最多 10 s。

### 天气

来自免费无需账号/key 的 [Open-Meteo](https://open-meteo.com)，Place 搜索 geocoding API，保存 `Name|latitude|longitude`；只有名字则查一次。数据署名 Open-Meteo，CC BY 4.0。

### 日历

使用私密 ICS 地址：

- Google Calendar：Settings > 指定日历 > Integrate calendar > Secret address in iCal format。
- Outlook / Microsoft 365：Settings > Calendar > Shared calendars > Publish a calendar > ICS link。
- Apple iCloud：Calendar > share > Public Calendar，也接受 `webcal://`。

识别单次、重复事件（每日、指定周几、每月、每年，支持间隔、次数、结束日期）、跳过/改期与取消。忽略全天事件，因为不是会议。带 `TZID` 的时间按本机时间处理，同一时区时正确。事件前 5 min 按键每秒闪橙。

## 实现

- `engine/live.rs` 一个 worker thread 只抓当前页按键及 dial 实际显示的值；首次显示时启动，没有可见值就休眠。各源按自身间隔，按下可立即刷新。结果作为 `IntegrationValue { key: "live:<hash of the source>", value: <JSON reading> }` 进入 engine，按键用时钟大数字，dial 用计时环显示。
- reading 为 `{text, num, sub, unit, places, attention, error, locked}`；绘制时再套格式和阈值，修改格式无需重新请求。
