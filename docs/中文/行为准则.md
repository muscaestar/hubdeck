# 行为准则

原文：[CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)。基线 `0cbdde3`，2026-10-22。

HubDeck 遵循 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。

友善、耐心，以善意理解他人，欢迎各种背景和经验水平的人，并围绕工作展开讨论。在 issue、pull request、discussion 以及代表项目的任何场合，都不接受骚扰、辱骂或人身攻击。

请私下向维护者 Przemysław Tarkowski 报告问题，邮箱为 przemotar+hubdeck@gmail.com。报告保密处理；维护者可删除评论、锁定讨论或封禁违反规则的人。
