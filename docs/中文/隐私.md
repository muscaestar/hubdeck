# 隐私

原文：[PRIVACY.md](../../PRIVACY.md)。基线 `0cbdde3`，2026-10-22。

HubDeck 没有账号、云端或遥测。保留的信息都在本机数据目录：Windows 为 `%APPDATA%\dev.hubdeck.app`，macOS 为 `~/Library/Application Support/dev.hubdeck.app`。

只有使用相应功能时，以下信息才会离开电脑：

| 功能 | 发送的信息与目的地 |
|---|---|
| 检查更新（默认开启，Settings > Updates） | 向 GitHub 请求最新 release |
| 显示当前播放与封面 | 从播放器给出的地址（Spotify 或 Apple 服务器）下载封面图片 |
| “Discover HubDeck”示例 profile | 设备显示其 Live 页面时，向 api.coingecko.com 请求 Bitcoin 价格；删除该 profile 或该按键即可停止 |
| 分享配置图库 | 从 GitHub 下载 gallery 列表 |
| 插件目录（Settings > Plugins） | 从 openactionapi.github.io 下载目录列表及图标；Install 时从作者 GitHub 下载插件文件 |
| 天气、日历、实时值 | 请求你指定的地址（天气使用 Open-Meteo） |
| OBS、Home Assistant、Streamlabs、Spotify、Twitch | 以你授予的权限请求对应应用或服务 |
| Stream Deck 插件 | 取决于各插件行为；它们是独立程序 |
| 控制台助手 | 通过你自己的 Claude Code，将消息，以及经你同意后的常用应用列表发送给 Anthropic；开始对话前不发送 |
| Report a problem | 浏览器打开 GitHub issue 表单；由你选择提交内容 |

按键使用次数统计（用于助手，以及引导次日“你从没用过这个旋钮”的提示卡）默认关闭；开启后数据保留在本机，关闭时清除。引导只查看本机模块与应用；音量环节的声音是 HubDeck 内置文件。

macOS 的分应用音量控制把该应用音频经 HubDeck 按设定音量播放（系统称之为 System Audio Recording）：不录制、不保存，HubDeck 退出后恢复直接播放。显示在按键上的 Claude Code session 只向 HubDeck 发送状态、项目文件夹名和工具名，不发送 prompts。
