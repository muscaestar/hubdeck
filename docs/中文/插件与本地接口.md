# 插件与本地 API

原文：[docs/PLUGINS.md](../PLUGINS.md)。基线 `0cbdde3`，2026-10-22。

HubDeck 把插件作为独立程序运行，经 `127.0.0.1` 的 WebSocket 通信。按键、dial 等概念沿用 Stream Deck SDK，另加推杆、圆形 dial 屏等本设备能力。任何语言均可：插件就是打开 WebSocket 的程序。

## 安装插件

把插件文件夹放入应用数据的 plugins 目录，重启 HubDeck：

| 系统 | 文件夹 |
|---|---|
| Windows | `%APPDATA%\dev.hubdeck.app\plugins\<plugin>\` |
| macOS | `~/Library/Application Support/dev.hubdeck.app/plugins/<plugin>/` |

动作出现在控件面板“What should it do?”下，以插件名分组。可运行示例在 `plugins/example-counter/`，需 Node 22+，无需 npm package。

## manifest.json

```json
{
  "id": "com.example.counter",
  "name": "Counter",
  "version": "1.0.0",
  "command": "node plugin.js",
  "actions": [
    {
      "id": "count",
      "name": "Count presses",
      "description": "Shown under the action in the inspector.",
      "icon": "zap",
      "inputs": ["press", "turn", "slide"],
      "params": [
        { "key": "start", "label": "Start at", "type": "number", "default": 0, "min": 0, "max": 100 },
        { "key": "mode", "label": "Mode", "type": "select", "default": "a", "options": [["a", "First"], ["b", "Second"]] }
      ]
    }
  ]
}
```

- `id` 与 action id：字母、数字、`.`、`-`、`_`。binding 保存 `<plugin id>/<action id>`。
- `command` 在插件目录运行，优先使用该目录下的程序，再找 `PATH`。
- `inputs`：`press` 为按键、旋钮和 dial 按下；`turn` 为旋钮、滚轮、dial 转动；`slide` 为推杆。
- 参数 `type`：`text`、`multiline`、`number`、`select`、`app`、`target`（文件或 URL）、`hotkey`。设置面板据此建表单，值以 `settings` 发送。
- `icon` 是内置图标名，见图标选择器。
- 顶层可选 `permissions` 表达使用能力，如 `["network", "files"]`。HubDeck 在 Plugins 页展示说明安装内容，不对插件做 sandbox。

## 协议

插件从环境取得 `HUBDECK_PORT`、自身 id `HUBDECK_PLUGIN` 和 `HUBDECK_TOKEN`，连接 `ws://127.0.0.1:<port>`，首先发送：

```json
{ "event": "register", "plugin": "<HUBDECK_PLUGIN>", "token": "<HUBDECK_TOKEN>" }
```

每条消息是含 `event` 的 JSON object。`context` 是 profile 中控件 id，例如 `keys.4`、`dial`、`knobs.1`、`<page>/keys.2`；长按、双击加 `:hold` 或 `:double`。

HubDeck 发往插件：

| event | 字段 | 时机 |
|---|---|---|
| `willAppear` | action, context, settings | 当前屏幕出现插件动作控件，注册后也发 |
| `willDisappear` | action, context | 切换 profile 或页面，控件离开 |
| `keyDown` / `keyUp` | action, context, settings | 按下 / 释放 |
| `dialRotate` | action, context, settings, ticks | 转动，ticks > 0 表示顺时针或向上 |
| `slide` | action, context, settings, value | 推杆移动，0..100 |
| `state` | state | 对 `getState` 的应答 |
| `error` | message | 插件发送的内容有误 |

插件发往 HubDeck：

| event | 字段 | 效果 |
|---|---|---|
| `setTitle` | context, title | 按键标签，null 恢复 profile 原值 |
| `setImage` | context, image | 按键图片，`data:image/png|jpeg|gif|webp|svg+xml;base64,...` URI |
| `setState` | context, state | true 使用“on”外观，默认红色或 profile 第二套外观 |
| `showFeedback` | value（0..1，可选）, caption | dial 显示数值环或说明 1.5 s |
| `setLed` | context（`knobs.1`、`faders.0`、`base`）, color（`#rrggbb`，null 恢复） | 点亮一个 LED |
| `setPanelImage` | image（data URI，null 关闭） | 整个 15 键面板显示同一图片，如游戏或图表；按键动作仍有效 |
| `switchProfile` | profile（id 或名称） | 激活 profile |
| `getState` | | 应答 `state`，含 profiles、活动 profile、page、前台应用 |
| `playGames` | on（true/false） | 启停设备游戏模式 |
| `log` | message | 写入 HubDeck 日志 |

## 本地 API

CLI、Claude Code hooks、MCP server 等脚本与工具使用同一 server。端口记录在 `<app data>/api-port`，首次启动创建的 token 在 `<app data>/api-token`，应保密。用 `"plugin": "api"` 和 token 注册，再发送上述消息，通过 `"control"` 或 `"context"` 指定控件，例如：

```json
{ "event": "setTitle", "control": "keys.0", "title": "Build OK" }
{ "event": "setState", "control": "keys.0", "state": true }
```

API client 也能收到所有控件输入，无论其绑定了什么：

```json
{ "event": "input", "control": "keys.3", "kind": "down" }
{ "event": "input", "control": "dial", "kind": "turn", "value": -2 }
{ "event": "input", "control": "faders.0", "kind": "slide", "value": 64 }
```

`kind` 为 `down`、`up`、`turn`（value 为刻度数）或 `slide`（0..100）。控件原来的动作仍会执行。API 设置的状态持续到再次改变或 HubDeck 重启。

### HTTP 接口

相同消息也可通过普通 HTTP 发送，便于脚本和 hooks。端口在 `<app data>/api-http-port`，header 为 `Authorization: Bearer <token>`；路径指定 event，body 包含字段：

```sh
TOKEN=$(cat "$APPDATA/dev.hubdeck.app/api-token")
PORT=$(cat "$APPDATA/dev.hubdeck.app/api-http-port")
curl -X POST "http://127.0.0.1:$PORT/api/setTitle" -H "Authorization: Bearer $TOKEN" \
     -d '{"control": "keys.0", "title": "Build OK"}'
curl "http://127.0.0.1:$PORT/api/state" -H "Authorization: Bearer $TOKEN"
```

HubDeck 收到消息后，`POST` 返回 `202`；`GET /api/state` 返回 profiles、活动 profile、page、前台应用与游戏模式。
